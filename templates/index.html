Deploying on Render (Free & Fast)

  1. Push your code to GitHub: git add . && git commit -m "Meet Tracker Web App" && git push
  2. Create a Web Service on Render: Log in to Render.com > Click New + > Web Service > Connect your GitHub repository.
  3. Render Settings (Auto-configured):
    • Runtime: Python 3
    • Build Command: pip install -r requirements.txt
    • Start Command: gunicorn app:app
  4. Add Your Google Token (Environment Variable): In your Render service settings > Environment Variables: Add GOOGLE_TOKEN_JSON and paste the text of your local token.json file. Render will automatically connect to your Google Meet account!
